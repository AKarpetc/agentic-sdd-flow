# ORD-42 — Customer order total endpoint

## Goal
Expose `GET /api/customers/{id}/orders/total` returning the customer's non-cancelled order total.

## Context
`Orders.Api` (ASP.NET Core minimal host, EF Core 8, PostgreSQL). `OrderService.TotalForCustomerAsync` already computes the total in memory from `IOrderRepository.ListByCustomerAsync`.

## Design
Add a `CustomerOrdersTotalQuery` handled by source-generated Mediator; the handler calls a new repository method `SumNonCancelledAsync(customerId)` that aggregates in SQL. The endpoint maps the query and returns `{ "customerId": "…", "total": 12.34 }`.

## Decisions
| id | choice | ADR |
|---|---|---|
| D1 | aggregate in SQL, not in memory | docs/adr/0001-aggregate-in-sql.md |

## Threats and mitigations
T1 enumeration of customer ids — the endpoint requires the existing customer-scoped bearer token.

## Data migration
None: a read-only query over existing columns; an index on `orders(customer_id, status)` will be evaluated separately.

## Out of scope
Currency conversion, pagination.

None.
