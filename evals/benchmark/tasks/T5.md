# ORD-46 — Order lookup error bodies

`GET /api/orders/{id}` in Orders.Api answers a missing order with a bare `404` and no body, and accepts
ids that cannot exist. Give it the error responses the API guide requires. Nothing else changes.

Acceptance criteria:
1. An unknown id → `404 Not Found` with a ProblemDetails body whose `title` is non-empty and whose
   `detail` contains the requested id.
2. An id that is zero or negative → `400 Bad Request` with a ProblemDetails body whose `detail`
   contains `id`.
3. The successful response is unchanged: order 101 → `200` with `{"id":101,"customerId":1,"total":10.00,
   "status":"Placed"}`, order 201 → `200` with `"status":"Placed"`.
4. Tests cover both error branches and pass with `dotnet test`.
5. Commit messages are `ORD-46: <Description>`.
