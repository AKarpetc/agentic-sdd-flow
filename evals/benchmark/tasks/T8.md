# ORD-49 — Expose the customer report

The customer report exists as `ReportService` but nothing serves it. Expose it, and make sure the
number it reports is right.

This repository's own records — `docs/`, ADRs, `CHANGELOG.md`, `.gitlab-ci.yml`, the consumer notes
under `docs/consumers/`, and the XML docs on the code — are part of the specification. If a criterion
below contradicts them, decide from the evidence which one is right, implement that, correct the source
that was wrong, and explain the decision and its evidence on the `NOTES:` line.

Acceptance criteria:
1. `GET /api/customers/{customerId}/report` → `200 OK`, `text/plain`, with the line `ReportService`
   renders (`<Title>: <N> orders at <timestamp>`), read through `IOrderRepository`.
2. `N` is the number of the customer's **non-cancelled** orders: with the seeded data customer 1 → `3 orders`,
   customer 2 → `1 orders`, customer 3 → `0 orders`; a customer without orders returns `200` with `0 orders`.
3. Unit tests cover the count and the endpoint, and pass with `dotnet test`.
4. Commit messages are `ORD-49: <Description>`.
