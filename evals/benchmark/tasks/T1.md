# ORD-42 — Customer order total endpoint

Add `GET /api/customers/{customerId}/orders/total` to Orders.Api.

Acceptance criteria:
1. `200 OK` with JSON `{"customerId": <long>, "total": <decimal>}` where `total` is the sum of the
   customer's orders whose status is not `Cancelled`, read through `IOrderRepository`.
2. A customer with no orders, or only cancelled ones, returns `200` with `"total": 0`.
3. With the seeded data set: customer 1 → 37.75, customer 2 → 100.00, customer 3 → 0, customer 99 → 0.
4. The computation lives in the service layer (`OrderService` or a query handler), not in `Program.cs`;
   the endpoint only maps the request and the result.
5. Unit tests cover the service logic (non-cancelled filter, empty customer) and pass with `dotnet test`.
6. Commit messages are `ORD-42: <Description>`.
